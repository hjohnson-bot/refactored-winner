# React `CFODashboard` — wired to live QuickBooks data

Drop-in React component (the one you pasted, with QuickBooks now actually
connected). Lives in this folder alongside the rest of `cfo-dashboard/`.

## Files

| File | Purpose |
|---|---|
| `CFODashboard.jsx` | The dashboard component. Auto-loads `data/snapshot.json` on mount and falls back to sample data if it isn't there yet. |
| `snapshotAdapter.js` | Maps `cfo-dashboard/data/snapshot.json` (built from live QuickBooks via the MCP) into the `{months: {...}}` shape the component expects. |
| `quickbooks-proxy-example.js` | Optional: server route showing how to call Anthropic + the QuickBooks MCP from your backend so the **Refresh from QB** button can trigger a fresh pull. |

## Quick start (no backend)

Recommended for most usage. The dashboard reads
`cfo-dashboard/data/snapshot.json`, which is regenerated by
`scripts/refresh.sh` whenever you want fresh QuickBooks data.

```bash
# 1. Refresh the snapshot from QuickBooks
cd cfo-dashboard
./scripts/refresh.sh         # uses Claude Code + the QuickBooks MCP

# 2. In your app:
```

```jsx
import CFODashboard from "./cfo-dashboard/react/CFODashboard.jsx";

export default function App() {
  return <CFODashboard snapshotUrl="/cfo-dashboard/data/snapshot.json" />;
}
```

The component auto-loads the snapshot on mount, switches the QB Connected
badge on, and tunes the period filters to the most recent verified months.
Clicking **Refresh from QB** re-fetches the snapshot — useful if a cron job
keeps it fresh.

## Live refresh button (with backend)

If you want the **Refresh from QB** button to actually trigger a fresh
QuickBooks pull from the browser, mount `quickbooks-proxy-example.js` as a
backend route and pass its URL:

```jsx
<CFODashboard
  snapshotUrl="/cfo-dashboard/data/snapshot.json"
  refreshUrl="/api/refresh-quickbooks"
/>
```

The button now: (1) POSTs to your refresh endpoint, (2) waits for the server
to rebuild the snapshot, (3) re-fetches `snapshot.json`. The browser never
sees the Anthropic API key or the QuickBooks OAuth token.

Required env vars on the backend:

```bash
ANTHROPIC_API_KEY=sk-ant-...
QB_MCP_URL=https://ai-inc.quickbooks.intuit.com/v1/mcp
```

## Why the original `connectQuickBooks` didn't work

The pasted code called `https://api.anthropic.com/v1/messages` directly from
the browser. Three problems with that:

1. **CORS** — `api.anthropic.com` doesn't allow browser origins.
2. **No auth header** — production requests need `x-api-key` and
   `anthropic-version`. Putting the key in client code would expose it.
3. **QuickBooks OAuth** — the QuickBooks MCP requires Intuit OAuth, which
   has to happen on a server you control.

This implementation routes around all three by putting the live pull on the
server (`quickbooks-proxy-example.js`) and giving the browser a snapshot
file to read, with the Refresh button as the trigger.

## Data shape

The component consumes:

```ts
{
  months: {
    "YYYY-MM": {
      year: number, month: 0-11, monthName: string,
      revenue, cogs, grossProfit, grossMargin (0-1),
      opex, netIncome, netMargin (0-1),
      ar, ap, cash, ebitda
    }
  }
}
```

`snapshotAdapter.js` builds this from `data/snapshot.json` by:

- Treating `verifiedMonths[]` (per-month QB pulls) as ground truth.
- Distributing FY 2024 / FY 2025 / YTD 2026 period totals across their
  months for periods without verified pulls (clearly tagged `_verified: false`).
- Stamping the period-end month with the live cash, A/R, A/P from the cash
  flow statement and forward-filling those values across earlier months.

If you want fully verified monthly data across more periods, run individual
month pulls via the QuickBooks MCP (the existing `scripts/refresh.sh`
prompt walks you through that) and `snapshotAdapter.js` picks them up
automatically.

## Props

```ts
<CFODashboard
  snapshotUrl="/data/snapshot.json"      // where to fetch the QB snapshot
  refreshUrl={null}                       // optional: backend endpoint that triggers a live pull
  anthropicProxyUrl={null}                // optional: alternate proxy returning {months, meta}
/>
```

All three are optional. With no props, the component uses `/data/snapshot.json`
and the Refresh button just re-fetches it.
